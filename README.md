# 🌐 글로벌 인프라 자산 뉴스 모니터 (프로토타입)

전 세계에 흩어진 인프라 자산 지역의 뉴스를 실시간 감시하고,
인프라에 심각한 영향을 줄 수 있는 사건(지진, 태풍, 정전, 폭발 등)이
감지되면 **경고등**으로 표시하는 대시보드입니다.

## 실행 방법

추가 설치 없이 파이썬만 있으면 됩니다 (표준 라이브러리만 사용).

```bash
python server.py
```

그 다음 브라우저에서 접속:

```
http://localhost:8000
```

종료는 터미널에서 `Ctrl+C`.

## 사용법

1. 좌측 **"모니터링 지역 선택"** 박스를 클릭해 드롭다운을 엽니다.
2. 관리 중인 자산이 있는 국가를 체크합니다 (검색창으로 필터 가능).
3. 선택한 국가가 지도에 핀으로 표시되고, 좌측에 경보 현황이 뜹니다.
4. 5분마다 자동으로 뉴스를 다시 수집합니다 (`지금 새로고침`으로 즉시 갱신).
5. 각 지역 항목을 클릭하면 관련 기사 목록이 펼쳐집니다.

선택한 국가 목록은 브라우저에 저장되어 다음 접속 시에도 유지됩니다.

## 경고등 기준

| 색 | 단계 | 의미 |
|----|------|------|
| 🟢 초록 | 정상 | 특이 사항 없음 |
| 🟡 노랑 | 주의 | 폭풍·시위·파업·지정학 긴장 등 잠재 위험 |
| 🔴 빨강 | 경고 | 지진·태풍·홍수·산불·정전·폭발·대피 등 급성 사건 (깜빡임) |

## 구조

- `server.py` — Google News RSS를 스크래핑해 국가별 뉴스를 수집하고
  키워드 기반으로 심각도를 분류하는 백엔드 (5분 캐시).
- `index.html` — Leaflet 지도 + 국가 드롭다운 + 경보 사이드바 프론트엔드.

## 🔥 속보 강조 (국가별 최신 위험 뉴스)

대응 보고서를 빨리 쓰려면 "방금 막 나온 뉴스"를 먼저 봐야 하므로,
발행 시각(신선도)을 국가별 목록 안에서 강조합니다.

- **속보 있는 국가가 맨 위로** 정렬되고, 카드 헤더에 `🔥 속보` 표시 → 어느 지역이 급한지 한눈에.
- **국가를 펼치면 그 안에서 위험(경고·주의) → 최신순**으로 정렬되어 최신 속보가 위에 옴.
- **신선도 배지**: 각 기사에 `🔥 방금`(60분 이내) / `🔥 속보`(3시간 이내) + 강조 배경.
- **진행 중 상황은 속보에서 제외**: 러시아-우크라이나 전쟁처럼 계속되는 이슈
  (`전쟁`·`긴장`·`제재` 태그)는 새 기사가 나와도 🔥로 표시하지 않음.
- 기준값은 `index.html` 상단의 `FRESH_NOW_MIN`, `FRESH_HOURS`, `ONGOING_TAGS`로 조절.

## 새 뉴스 알림

새로고침(자동 5분/수동) 때 **이전에 없던 새 기사**가 감지되면 알려줍니다.

- **화면 토스트**: 우측 상단에 "🔴 미국 · 새 경고 뉴스 2건" 식으로 팝업 (클릭하면 해당 지역으로 이동). 9초 후 자동 사라짐.
- **소리**: 심각(critical) 뉴스는 급한 비프음, 그 외는 부드러운 알림음. 좌측 `🔊 소리` 체크로 on/off. (외부 파일 없이 Web Audio 로 생성)
- **데스크톱 알림**: `🔔 데스크톱 알림` 체크 시 브라우저 권한을 요청하고, 창을 안 보고 있어도 OS 알림이 뜹니다.
- **NEW 뱃지**: 뉴스 목록에서 새로 뜬 기사에 빨간 `NEW` 표시.

이미 본 기사 링크는 브라우저에 저장되어(최근 800개) 재접속해도 기억하므로,
같은 기사로 반복 알림이 오지 않습니다. 처음 접속하는 사용자는 최초 1회는
기준선만 잡고 알림을 울리지 않습니다(모든 기사를 새 뉴스로 착각하지 않도록).

## 최근성 필터

경고등이 옛날 뉴스(과거 지진 회고 기사 등)로 잘못 켜지지 않도록,
각 기사의 실제 발행일을 파싱해 **최근 48시간 이내 기사만** 사용합니다.
이 기준은 `server.py` 상단의 `MAX_AGE_HOURS` 값으로 조절할 수 있습니다.
(예: 최근 24시간만 보려면 `MAX_AGE_HOURS = 24`)

## 한계 (프로토타입이라 감안)

- 심각도 분류는 단순 키워드 매칭이라 오탐/누락이 있습니다.
  (예: 과거 사건 회고 기사, 영화·게임 제목 등)
  → 실제 운영 시엔 LLM 분류나 재난 전용 API(USGS 지진, 기상청 등) 연동 권장.
- 뉴스 출처가 Google News 한 곳입니다. 다중 소스로 확장 가능.
- 국가 단위 핀포인트입니다. 실제 자산의 도시/좌표 단위로 좁힐 수 있습니다.
- 인증/접근제어가 없습니다. 사내망 배포 시 추가 필요.
